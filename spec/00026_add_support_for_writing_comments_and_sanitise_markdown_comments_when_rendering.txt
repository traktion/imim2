As a blog reader
I want to be able to write new comments on an article and read existing comments safely
So that I can add feedback and read feedback from others

Given the source of article comments cannot be controlled and sanitised
When reading comments
Then assume that they may include unsavoury code injection
And strip out all control characters and verge on the side of safety before rendering the comment text
And only include alphanumeric characters and basic punctuation using a simple regular expression
And strip any URLs that may be embedded
And strip common swear words  (include a list in a blocked words file)
And add a remark in the code where more variations can be added

Given the source of comments may be plain text or basic markdown
When rendering the comment
Then if it is markdown, then sanitise it and then convert it into simple HTML
And if it is plain text, then sanitise it and then convert it into simple HTML
And to test what the comment format may be, assume it is markdown first and attempt to convert it

Given if 'Write a comment' is clicked the user wants to write a comment
When writing a new comment
Then present a simple text editor below the 'write a comment' link
And present a 'publish' button
And when the 'publish' button is clicked then add the new comment
And grey out or disable the text editor and 'publish' button

Given each comment must be submitted as public data and then stored to a graph entry
When adding a comment
Then create the public data by calling POST /anttp-0/binary/public_data with the comment text,  with 'Content-Type: application/octet-stream' and a binary data payload 
And then create a graph entry by calling POST /anttp-0/graph_entry with the 'resolver' data key, and the comment key as the graph entry name, and use the address return when creating public data as the content
And an example payload is below:

```
{
  "content": "03d823ba9c2caadf69b477e1ab1393a6d3df63a4e165b79955ad80e737d9522b",
  "name": "imim_blogname_articlename_comment1"
}
```

Given a comment has been created as a graph entry
When after the comment has been created
Then if it was successful, then render the comment in the correct location in the list of comments
And if it was a failure, display an error message and un-grey out / enable the text editor and the 'publish' button again to allow the user to retry
